# Análise de dados de sensoriamento utilizando pthreads


## Instruções de execução

### Compilação manual

```bash
gcc -pthread cJSON.c processData.c main.c -o saida
```

### Execução

### Linux

```bash
./saida
```

### Windows

CMD:
```cmd
saida.exe
```

Powershell:
```powershell
.\saida.exe
```
